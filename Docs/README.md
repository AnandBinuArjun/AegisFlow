# AegisFlow Documentation Pack

This pack contains the initial product and security documentation for AegisFlow.

## Documents
- `SECURITY_REQUIREMENTS.md` — minimum product security requirements and release gates.
- `THREAT_MODEL.md` — assets, trust boundaries, threats, mitigations, and verification plan.
- `ARCHITECTURE.md` — logical components, data model, workflows, deployment, and APIs.
- `SECURITY_ARCHITECTURE.md` — enforcement layers, identity, tenancy, AI boundary, remediation protocol, and audit.
- `PRODUCT_DEVELOPMENT.md` — MVP scope, repository structure, phases, backlog, metrics, and launch checklist.
- `PROMPT.md` — phased implementation prompt for a coding agent.

These documents describe a proposed baseline, not proof that controls have been implemented. Update them as implementation decisions become concrete.
